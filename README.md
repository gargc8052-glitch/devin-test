# AI Agent Studio

A simple Next.js app with a dark, responsive homepage for describing and drafting AI agents. Agent drafts are kept in local component state only — no external APIs or paid services.

## Getting started

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
